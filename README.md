# IBM Data Science Professional Certificate - Capstone Project

## Project Overview
This repository contains the code, data, and final presentation for the **SpaceX Falcon 9 First-Stage Landing Prediction** capstone project. The goal of this project is to predict whether a Falcon 9 first stage will land successfully, utilizing data collection, SQL analysis, interactive mapping, Plotly Dash dashboards, and machine learning classification models.

## Key Components & Workflow
1. **Data Collection:** Gathered Falcon 9 launch data via SpaceX REST API and web scraping (BeautifulSoup).
2. **Data Wrangling & EDA:** Cleaned datasets, engineered target variables (landing success/failure), and analyzed trends via SQL and Pandas.
3. **Interactive Visualization:** Developed interactive maps using Folium and a web application dashboard using Plotly Dash.
4. **Predictive Analysis (Classification):** Trained and evaluated Logistic Regression, Support Vector Machines (SVM), Decision Trees, and K-Nearest Neighbors (KNN) models. Achieved robust test accuracy (~83.33%).

## Repository Contents
* `notebooks/`: Complete Jupyter notebooks for each step of the pipeline.
* `datasets/`: Processed CSV datasets used for modeling and queries.
* `scripts/`: Python source code, including the Plotly Dash interactive app script.
* `presentation/`: Final slide deck presentation file (.pdf).
